## Placeholder Images

Until you add real images, the site will show placeholder backgrounds. To add your images:

1. Take or source high-quality photos of your dishes
2. Optimize them for web (compress without losing quality)
3. Name them according to the list above
4. Place them in the appropriate directory

## Image Optimization Tips

- Use tools like TinyPNG or Squoosh to compress images
- Ensure good lighting and appetizing presentation
- Keep consistent styling across all dish photos
- Consider using a professional food photographer
